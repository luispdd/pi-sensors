## Why

The mesh network currently logs sensor data to SD cards on the logger node, but lacks an API for a central controller to safely and reliably extract this data. We need a robust sync mechanism that avoids data loss during concurrent flush operations and properly deduplicates readings across multiple loggers without missing data.

## What Changes

- **Sensor Nodes (pico-1w)**: Add NTP time synchronization on boot and periodically. Update the `/sensors` CoAP response to include the timestamp generated by the sensor node at the time of reading.
- **Data Logger (pico-2w) Storage**: Modify the SD storage logic to write a unified daily file (`YYYY-MM-DD.csv`) instead of splitting files by device name.
- **Data Logger (pico-2w) Sorting**: Update the in-memory buffer flush logic to strictly sort records by `(timestamp, device_id)` prior to appending them to the SD card, ensuring a deterministic order.
- **Data Logger Sync API**: Introduce a `GET /log?size=N&cursor=filename:line` endpoint to the CoAP server. This allows a controller to paginate through the unified daily files safely. The `cursor` parameter is optional (defaults to the beginning of the oldest file) and the `size` parameter is mandatory. The `cursor` is a line number in the file.

### New Capabilities

### Modified Capabilities
- `core/data-logger`: Requires writing a unified daily file and strictly sorting the in-memory buffer prior to flushing.
- `core/iotmesh`: Introduces the `GET /log` endpoint with cursor-based pagination.
- `core/sensor-monitoring`: Sensor nodes are now required to maintain NTP time and include their own timestamps in their sensor readings.

## Impact

- `boards/pico-1w/main.py` and `services`: Will require NTP synchronization integration like the `pico-2w` have.
- `boards/pico-2w/hardware/sd_storage.py`: Modifies file naming and writing logic.
- `boards/pico-2w/services/data_logger.py`: Implements strict sorting of the memory buffer before flushing.
- `boards/pico-2w/services/coap_server.py`: Adds the `/log` HTTP/CoAP endpoint for sync.
